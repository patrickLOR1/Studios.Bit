# Fotogramas de las referencias

Los siete fotogramas originales del usuario están en el ZIP **StudiosBit_Creative_Direction_v0.2_Codex_Integracion.zip**.

Por tratarse de capturas de contenidos de terceros y ser este un repositorio público, los fotogramas no se subieron a GitHub. Para disponer de ellos en Codex, extraer el ZIP en la raíz local del proyecto: el contenido quedará en esta carpeta.

La skill y el catálogo de patrones son operativos aunque los JPG no estén disponibles localmente.
